## OpenWiki

This repository uses OpenWiki for recurring code documentation. Start with `openwiki/quickstart.md`, then follow its links to architecture, workflows, domain concepts, operations, integrations, testing guidance, and source maps.

OpenWiki updates are run manually and locally; no scheduled or manually dispatched GitHub Actions workflow should be created or restored for this repository. Do not hand-edit generated OpenWiki pages unless explicitly asked; when updating documentation, inspect source changes first and edit only affected pages.
