## OpenWiki

This repository uses OpenWiki for recurring code documentation. Start with `openwiki/quickstart.md`, then follow its links to architecture, workflows, domain concepts, operations, integrations, testing guidance, and source maps.

The wiki is maintained locally from the umbrella repository root with the installed OpenWiki CLI and local OpenCode Go subscription: `openwiki code --update --print`. Scheduled and manually dispatched OpenWiki GitHub Actions are retired; do not restore them. Do not hand-edit generated OpenWiki pages unless explicitly asked; prefer updating source code/docs and letting OpenWiki regenerate.
